CONVENCIÓN DIMENSIONAL
- dimensiones: hasta 0.001 mm;
- incertidumbres: micras enteras;
- cálculos internos con precisión adicional.

INSTALACIÓN
1. Descomprimir el ZIP.
2. Copiar todo el contenido directamente sobre la raíz de Portal_Publicacion_V1.
3. Aceptar reemplazo de:
   - streamlit_app.py
   - pages/inicio.py
4. Los archivos del módulo Medición e Incertidumbre son nuevos.
5. Ejecutar:
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe -m streamlit run streamlit_app.py

DEPENDENCIAS
El módulo utiliza streamlit, plotly y pandas.
