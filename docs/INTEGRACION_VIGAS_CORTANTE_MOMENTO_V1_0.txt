REFINAMIENTO SOLICITADO
Las reacciones ya NO se muestran con etiquetas de texto plano.
Cada reacción se representa como fórmula LaTeX, por ejemplo:

R_A = 10.000 kN
M_A = 25.000 kN·m

con R_A, R_B, M_A y M_B tipografiados matemáticamente por KaTeX/LaTeX.
